# Changelog

All notable changes to ItemSize are documented here.

## 1.0.0

First release.

- Per-item size for three views: **Ground**, **Hand** (first and third person) and **Inventory**.
- Editor menu (default key **O**) with search, filters (All / Block / Tool / Armor / Edited) and a live preview.
- Size by slider, **-** / **+** buttons, mouse wheel, arrow keys, presets (50 / 100 / 150 / 200 %) or by typing a percentage.
- **All views** switch to change the ground, hand and inventory size together.
- Global ON / OFF switch, reset per item and reset all.
- Settings are saved automatically to `config/itemsize.json`.
- Available in English and German.
